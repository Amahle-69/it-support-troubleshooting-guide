
# Troubleshooting Guide: Slow Windows Computer

## 1. Overview

**Issue:** A Windows computer is running slower than expected.

**Objective:** Identify possible causes of poor performance, apply appropriate troubleshooting steps, and verify whether performance improves.

**Environment:** Windows 10 or Windows 11 computer.

## 2. Symptoms

A user may report one or more of the following symptoms:

- Applications take a long time to open.
- The computer freezes or becomes unresponsive.
- Switching between applications is slow.
- The computer takes a long time to start.
- The system responds slowly to keyboard or mouse input.

## 3. Initial Questions

Before making changes, ask the user:

1. When did the problem first occur?
2. Is the computer always slow, or does it happen at certain times?
3. Does the issue affect one application or the whole computer?
4. Were any new applications or updates installed recently?
5. Have any error messages appeared?

Document the answers before troubleshooting.

## 4. Possible Causes

Potential causes include:

- Too many applications running simultaneously.
- High CPU, memory, or disk usage.
- Too many applications launching at startup.
- Insufficient available storage space.
- Pending operating system updates or a recent software issue.
- Unwanted or malicious software.
- Hardware limitations or a failing component.

These are possibilities to investigate, not confirmed causes.

## 5. Troubleshooting Procedure

### Step 1: Check the scope of the problem

Ask the user which applications are affected and whether the problem started recently.

Check whether the entire computer is slow or only one application.

**Reason:** This helps narrow down where the investigation should begin.

### Step 2: Restart the computer if appropriate

Save open work and close applications before restarting.

After restarting, check whether performance improves.

**Reason:** A restart can clear some temporary problems and end processes that are no longer needed.

### Step 3: Inspect resource usage

1. Press `Ctrl + Shift + Esc` to open Task Manager.
2. Select the Processes tab.
3. Review the CPU, Memory, and Disk columns.
4. Observe whether any resource remains heavily utilized.
5. Identify the process involved before taking further action.

Do not end unfamiliar system processes or security software simply because usage is high.

**Reason:** High resource usage can help identify which application or system component needs further investigation.

### Step 4: Review startup applications

1. Open Task Manager.
2. Select Startup apps.
3. Review applications configured to launch automatically.
4. Identify nonessential applications that do not need to start with Windows.
5. Disable only applications you recognize and understand.

Do not disable essential drivers or security applications.

**Reason:** Unnecessary startup applications can increase startup time and background resource usage.

### Step 5: Check available storage

1. Open Settings.
2. Select System, then Storage.
3. Review the available disk space.
4. If space is limited, review temporary files and other storage categories.
5. Remove only files you understand and no longer need.

Avoid deleting personal files or unfamiliar system files without authorization and verification.

**Reason:** Low available storage can contribute to performance and update problems.

### Step 6: Check Windows updates

1. Open Settings.
2. Navigate to Windows Update.
3. Check for available updates.
4. Follow the organization's update procedures if the computer is managed.
5. Restart if required and appropriate.

If the problem began immediately after an update, record that information before considering further action.

### Step 7: Run a security scan if indicated

If there are signs of unwanted software or suspicious activity, use Windows Security to perform an appropriate scan.

Follow organizational security procedures if the device belongs to an employer.

**Reason:** Unwanted or malicious software can sometimes affect system performance.

## 6. Verify the Result

After troubleshooting:

- Reopen the applications that were previously slow.
- Check whether the computer responds more quickly.
- Compare CPU, Memory, and Disk usage with the earlier observations.
- Ask the user whether the problem has improved.
- Record which steps were completed and their outcomes.

Do not record an issue as resolved unless the result has been checked.

## 7. Escalation

Escalate the issue to a senior technician or appropriate support team if:

- Performance remains poor after reasonable troubleshooting.
- Hardware failure is suspected.
- The device repeatedly crashes or displays errors.
- Security concerns require specialist investigation.
- Administrative access or additional authorization is required.

Include the symptoms, observations, tests performed, and results in the escalation notes.

## 9. Skills Demonstrated

- Structured troubleshooting.
- Windows operating system fundamentals.
- Task Manager and resource monitoring.
- Basic storage management.
- Security awareness.
- Technical documentation.
- User communication and escalation.

## 10. Key Lesson

Effective troubleshooting begins with gathering information and testing possible causes. Every action should have a clear purpose, and the final outcome should be verified and documented.
